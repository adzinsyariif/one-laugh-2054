one funny line, at most 140 characters, judged pairwise by an AI comedy judge.

## Entry

## How it works

`main.ts` (Node 22, no dependencies) writes the entry line to `/output/entry.txt`,
which is what the grader reads. For local testing, set `OUTPUT_PATH` to write
somewhere else:

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
cat /tmp/entry.txt
```

See `candidates.md` for the lines considered and why this one was picked
against the judge's published criteria.
